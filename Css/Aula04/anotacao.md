#box model
 O Css encxerga os elementos do HTML como caixas que possuem alguma propriedades

 #Margem 
 Margem é o espaço  que distancia um elementos do soutro, ou seja, é essa medida que faz um paragrafo ie para longe de uma Imagem 
  
  #Border
  Para contonar um elementos podemos configurar uma borda, a borda nad mais é doque uma linha envolta do elemento que fica entre a margem e o padding

  #Padding
   Se a margem é o espaço externo de um elemento,  o  padding é o espaço espaço interno, ele quem separa o conteúdo, da borda e da margin.
